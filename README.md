# Executive Chef Control Center

Türkçe mutfak yönetimi ve kontrol paneli. Bu depo, restoranın personel, reçete, maliyet, HACCP, eğitim ve raporlama süreçlerini bir araya getiren uygulamanın kaynak kodunu içerir.

**Gizlilik:** Kod herkese açıktır; gerçek personel bilgileri, satış kayıtları, parolalar ve restoran verileri bu depoya yüklenmemelidir.

Kurulum ve kapsam ayrıntıları proje dosyalarında açıklanacaktır.
